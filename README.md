# 正誤トレーナー（SeigoTrainer）

CSV形式の問題集を読み込んで、アプリ内に保持し、正誤判定しながら解ける学習アプリです。

## できること

- CSVファイル（`番号,表面,裏面,解説`）を読み込んで、問題集としてアプリ内に保存（複数可・削除可）
- 出題範囲を問題番号で指定（例：No.1〜40）。20/40/50/100問ごとの区切りボタンからも選べます
- ランダム並べ替え（シャッフル）のオン/オフ
- 裏面が①〜④などの選択肢記号なら、タップで自動判定。そうでない問題は「答えと解説を見る」→自己判定
- 回答後に正解と解説を表示。結果は問題集ごとに記録され、「間違えた問題だけ」の出題や再挑戦ができます

## CSVの形式

```csv
番号,表面,裏面,解説
1,"問題文（選択肢①〜④を含む）",②,"解説文"
```

- 文字コードは UTF-8（BOM可）/ Shift_JIS に対応
- クォート内のカンマ・改行に対応。タブ区切り（TSV）も自動判定します
- ヘッダー行があってもなくても読み込めます

## ビルド方法

GHUploader でこのリポジトリを作成／選択して ZIP をアップロードすると、GitHub Actions（macos-26）が未署名 IPA をビルドします。成果物 `SeigoTrainer-ipa` をダウンロードし、LiveContainer にインポートしてください。

## 備考

- データはアプリの Documents 内に保存されます（外部送信なし）
- ファイル選択は UIKit のドキュメントピッカー（asCopy）を使用し、LiveContainer でも動作します

## v1.1での変更
- ZIPファイルを直接読み込めるようにした（ZIP内のCSV/TSVは、それぞれ1つの問題集として追加される）
- 問題集の長押しメニューから、名前変更・複製・他の問題集と合わせる（マージ）・削除ができるようにした
  - マージでは元の2つは残り、合わせた新しい問題集ができる。問題番号は重複回避のため先頭から振り直す
- 出題設定に「問題一覧・編集」を追加（1問ずつ表面・裏面・解説の編集と削除が可能。問題番号は成績のキーのため変更不可）
- 「区切りから選ぶ」セクションを削除（範囲の開始・終了を手で指定する方式は残置）

## v1.2での変更
- 問題集の中に「セクション」（章分け）を自分で作れるようにした
  - 出題設定の「セクションを管理」から作成・名前変更・削除（削除しても問題は未分類に戻るだけ）
  - 問題の振り分けは「問題一覧・編集」で問題を開き、セクションを選ぶ
  - 出題設定でセクション絞り込みが可能（範囲指定・全問・間違いのみの各モードと併用可）
  - 既存の保存データ（v1.1以前）もそのまま読み込める（セクションは空として扱う）
- 問題集一覧に「選択」モードを追加（右上の「選択」→チェックを付ける）
  - 「全部で作る」: 選択した問題集すべての問題を集めた新しい問題集を作成
  - 「間違いだけで作る」: 選択した問題集すべての中で、最後に間違えた問題だけを集めた新しい問題集を作成
  - どちらも元の問題集は残り、問題番号は先頭から振り直す。セクション分けも引き継がれる
